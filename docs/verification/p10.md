## Testes automatizados

`npm run lint`, `npm run typecheck`, `npm test` e `npm run build` executados sem erros. Vitest com MSW: **37 testes aprovados em 9 arquivos**, incluindo cliente HTTP (CSRF, idempotência, problem+json, expiração). MSW intercepta somente nos testes; os contratos simulados seguem docs/development/consumer-contracts.md.

## Navegador

Playwright com Chromium real: **40 verificações aprovadas**.

- 12 páginas (7 do cliente, 5 do artista) em 360, 768 e 1280 px sem rolagem horizontal, com capturas de página inteira em test-results/screens/ (não versionadas).
- Recarregar /mensagens/c1 mantém a conversa e o histórico.
- Sugestões operadas só por teclado (setas, Enter, Escape).
- Diálogo de aceite recebe o foco, mantém o foco dentro e o devolve ao botão de origem.
- Abas do perfil respondem às setas.

As respostas do backend nessas checagens são sintéticas (e2e/mock-backend.ts) e servem somente para layout e teclado. Não são fonte de dados do website.

## Pendente para fechar T10.10 e M6

Executar em máquina com o ambiente da [integração P09](../development/integration.md) e certificado localhost confiável:

1. `INKLINK_BFF_URL=https://localhost:5292`, certificado PEM em INKLINK_DEV_CERT/KEY, `npm run dev`.
2. Cliente: login por janela própria, Descobrir, Explorar com sugestões, favorito, pedido com flash, aceite de proposta, conversa com envio e recarga.
3. Artista: apresentar proposta, confirmar reserva e verificar conflito, encerrar com reserva futura (rejeitado) e após o término (concluído), conclusão de sessão, lançamentos e painel.
4. Sessão expirada após 5 minutos durante um formulário: aviso, novo login e reenvio sem duplicidade.
5. Publicação: `npm run build` servido por proxy reverso na origem do BFF com fallback de SPA; recarregar endereço profundo.

Este ambiente de execução não possui .NET nem Docker com o backend, e por isso o roteiro real não foi executado aqui.
